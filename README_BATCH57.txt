Batch57：现场运维 UI / 代码优化

本批次保持原有四个主功能页、现有控件 objectName 和诊断流程兼容，重点优化现场人员首屏判断效率：

1. 现场诊断页新增“现场状态 / 当前阶段 / 下一步建议”摘要卡。
   - 等待诊断：提示先连接设备或开始一键现场诊断。
   - 正在诊断：显示当前工作流阶段。
   - 异常/关注：自动提示优先处理的诊断层。
   - 正常：提示可继续抓包或协议分析。

2. 一键现场诊断按钮强化为首要操作入口，并补充连接、停止诊断的现场操作提示。

3. 抓包快速过滤逻辑重构为 packetMatchesCaptureQuickFilter()，统一处理：
   - 全部 / SYN / RST / Payload / IEC104 / 异常
   - IP / 端口 / 协议 / Info / HEX 搜索
   - 兼容没有保存 ParsedPacket 模型的旧行文本过滤

4. 视觉样式微调：首屏摘要、状态卡、主操作按钮层级更明显；正常/关注/异常/运行中状态保持统一的运维语义。

验证：
- MainWindow.ui XML 解析通过。
- tests/*_contract.cmake 全部通过（含 Batch57 新增契约）。
- 当前执行环境未安装 Qt5/Qt6 开发包，因此未能在 Linux 容器内完成实际 C++/Qt 编译运行；请在已有 VS2022 + Qt 环境执行 configure_vs2022.bat 后构建。
