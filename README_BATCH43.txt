RC13 Batch43 - 实时抓包/串口参数/快捷指令收敛

1. 实时抓包“新建抓包任务”移到“实时抓包：报文与统计”标题栏右侧，不再单独占据参数区一行。
2. 终端通讯选择“串口”时，隐藏终端IP、终端端口、终端角色和Ping终端；切回“网口”立即恢复。
3. 现场诊断“每段抓包 / 连接等待”高级参数始终直接显示，不再默认折叠。
4. 快捷指令继续按分类/搜索/四列表格组织，并补充：reboot、默认路由、主/备WAN摘要、监听端口、抓包接口候选、模组/信号摘要、系统版本/时间/负载等常用现场命令。
5. reboot 仍走现有危险命令二次确认；模组摘要不读取 IMSI/IMEI/ICCID。
6. WAN接口规则保持Batch42：没有可信WAN就显示“未检测到 WAN 接口”，不会用br0顶替；终端LAN侧抓包仍可使用br0。
