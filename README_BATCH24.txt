FourFaith RouterDiag v1.2 RC12 - Batch24

本批次变更：
1. “路由器连接”增加“网口 Telnet / 串口 Telnet”两种进入路由后台的方式。
2. 串口模式自动枚举 PC 当前可用串口，显示端口名和系统提供的设备描述；串口模式下每 2 秒刷新一次，并保留当前选择，同时提供手动“刷新”。
3. 串口默认参数为 115200 / 8 数据位 / 1 停止位 / 无校验（8N1），无流控；波特率、数据位、停止位、校验位可调整。
4. 打开串口成功后自动发送一个回车（\r），随后复用原 Telnet 用户名/密码登录状态机进入路由后台。
5. 登录后的设备识别、WAN诊断、Ping、AT模组识别等控制命令统一复用已登录的控制通道。
6. 网口模式继续维持原控制/抓包双 Telnet 会话，不改变原抓包行为。
7. 串口模式只有一个物理控制台，抓包改用 tcpdump -xx 文本方式，停止时发送 Ctrl-C，再转换为 PCAP，避免二进制 PCAP + stty raw 导致串口控制台无法安全停止/恢复。
8. Windows 单文件发布校验增加 Qt6SerialPort.dll，避免部署遗漏串口运行库。

说明：
- 串口只是进入路由后台的另一种入口；主界面诊断流程仍以“登录成功”为后续操作前提。
- 独立实时模块日志使用额外 Telnet 会话，串口单通道模式不会后台启动该独立会话；主流程的设备检测/AT识别仍正常通过当前串口控制台执行。
- 当前 Linux 构建环境未安装 Qt5/Qt6 SDK，无法在本地执行 Qt 编译和 QtTest；静态契约与 UI XML 已验证。
