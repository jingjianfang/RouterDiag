RC13 Batch45 - 全接口抓包 / 串口分类 / 多窗口 / 界面精简

本批次在 Batch44 的诊断逻辑基础上，仅扩展抓包工作区和界面可用性：

1. 抓包接口改为可编辑下拉选择：
   - 自动列出设备发现结果中的全部真实接口；
   - 包括 usb0/ppp0/tun0/tap0/wwan/rmnet/vlan/br0/lo 等实际存在的接口；
   - 额外支持 tcpdump 的 any；
   - 支持手工输入任意安全接口名；
   - “刷新接口”重新读取设备接口，适合 VPN 建立后刷新 tun0/tap0。
2. 抓包场景与实际接口解耦：
   - WAN 抓包默认使用可信 WAN；
   - 主站抓包默认使用 WAN，但允许手工改为 tun0 等真实经过接口；
   - 终端网口抓包默认 br0，但允许手工改接口；
   - 新增“自定义抓包”，接口和过滤条件完全由用户决定；
   - 手工抓包接口不会反向改变 WAN 诊断结果。
3. “BPF”界面文字改为“抓包过滤条件”，允许直接输入 tcpdump 过滤表达式。
4. 恢复并强化多窗口抓包：抓包控制区直接显示“新建抓包窗口”；独立窗口接口也为可编辑下拉框。
5. 终端通讯选择串口时：
   - 继续隐藏终端 IP / 端口 / 终端角色 / Ping；
   - 实时抓包详情新增“串口通信”和“串口与网络时间线”；
   - 网络抓包与串口日志分类展示；
   - 时间线仅表示时间邻近，不自动声称两条记录属于同一业务帧。
6. 连接区 1280 宽度下状态信息独占一行，避免长登录失败文字覆盖历史连接/工作视图控件。
7. 工具快捷指令分类简化为“只读检查 / 抓包分析 / 日志 / 维护操作 / 自定义”，按钮名称改为“查看网口、查看进程、查看模组和信号”等通俗文字；底层命令保持可见。
8. 设备接口采集优先使用 ifconfig -a，以便包含更多实际接口。

Windows + VS2022 + Qt 6.8.3 最终动态回归应为 59 tests。
